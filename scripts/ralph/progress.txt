## Codebase Patterns

### SQLAlchemy Model Patterns
- Base class: `from .base import Base` using SQLAlchemy 2.0+ DeclarativeBase
- Use `Mapped[]` type hints with `mapped_column()`
- UUID primary key: `server_default=func.gen_random_uuid()`
- Foreign keys: `ForeignKey("table.id", ondelete="CASCADE")` with `index=True`
- DateTime: `DateTime(timezone=True)` with `server_default=func.now()` for created_at
- JSONB: Use `JSON` type, maps to JSONB in PostgreSQL
- Use TYPE_CHECKING guard for relationship type imports
- Export models in `__init__.py` alphabetically

### Relationship Patterns
- Child side: `relationship("Parent", back_populates="children")`
- Parent side: `relationship("Child", back_populates="parent", cascade="all, delete-orphan")`
- Use string references to avoid circular imports
