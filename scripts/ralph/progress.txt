## Codebase Patterns (from previous feature work)
- Dependencies in pyproject.toml use `>=` version constraints (not `~=`) for most packages
- Dependencies are listed alphabetically in pyproject.toml
- Use `uv run` to execute commands in the project's venv (not the system Python)
- Backend models go in `backend/src/models/` and must be exported in `__init__.py`
- Use JSON from sqlalchemy core instead of JSONB from postgresql dialect for SQLite test compatibility
- unique=True already creates an index, no need for index=True
- One-to-one relationships use uselist=False on parent side
- Use TYPE_CHECKING imports to avoid circular dependencies
- Frontend API hooks go in `frontend/src/lib/api/` with React Query
- Use URLSearchParams.append() for array query params
- Recharts uses "use client" directive for Next.js App Router
